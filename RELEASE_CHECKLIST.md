# CoDRBench publication checklist

- [ ] Freeze the train/test split and version number.
- [ ] Verify the two-field JSON schema and dataset counts.
- [ ] Verify SHA-256 checksums from a clean checkout.
- [ ] Include the dataset description and paper mapping.
- [ ] Select and include dataset and code license files.
- [ ] Add citation metadata for the published version.
- [ ] Confirm that no credentials, private files, or local build artifacts are tracked.
- [ ] Add the immutable repository or release URL to the revised manuscript.
