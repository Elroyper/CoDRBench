# Paper mapping

The repository contains the Experiment 2 (Open-Role Deception) corpus that
accompanies the paper:

[*When Thinking LLMs Lie: Unveiling the Strategic Deception in Representations
of Reasoning Models*](https://arxiv.org/abs/2506.04909)

The repository version is organized as 188 training cases and 60 test cases.
The exact subset used for any individual analysis should be identified by the
dataset version and split recorded in the corresponding experiment materials.
