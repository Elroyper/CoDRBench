# Data release placeholder

No CoDRBench dataset files have been released.

The private staging snapshot (188 training cases and 60 test cases) remains in
the internal review workspace and is intentionally excluded from this Git
repository. The repository-level `.gitignore` blocks files under `data/` so
that a dataset cannot be added accidentally.

When the first public release is authorized, this directory will contain a
versioned subdirectory with the validated splits, metadata, dataset card,
release manifest, and SHA-256 checksums. Adding those files will require an
explicit review and an intentional update to `.gitignore`.
